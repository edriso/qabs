# قَبَس

مقاطع قصيرة مترابطة من القرآن الكريم، للصلاة والحفظ والتدبر.

**[افتح قبس](https://edriso.github.io/qabs/)**

يعرض قبس مجموعة منتقاة من المقاطع القرآنية القصيرة في واجهة عربية هادئة.
يمكن تصفيتها حسب الموضوع، والتنقّل بينها أو نسخها ومشاركة رابط مباشر لها.
لا حسابات، ولا خادم، ولا تحليلات؛ كل شيء يعمل في المتصفح.

## الموضوعات

الصبر، والتوبة، والجنة، والآخرة، والتوكل، والدعاء، والأخلاق، والدعوة إلى
الله. في كل موضوع أربعة مقاطع كاملة متصلة السياق، والنص القرآني هو مركز كل
شاشة.

## أمانة النص

النص العثماني من [مشروع تنزيل](https://tanzil.net)، الإصدار 1.1. الأصل
محفوظ في المستودع ببصمة SHA-256 ثابتة، والمقاطع مولّدة منه آليًّا بلا تعديل.
تقارن الاختبارات كل آية مع الأصل حرفًا بحرف، وتتحقق من اتصال أرقام الآيات.
التفصيل الكامل في [`data/README.md`](data/README.md)، وشروط المصدر في
[`NOTICE`](NOTICE).

## التشغيل المحلي

```sh
npm install
npm run dev
```

وللتحقق قبل الدفع:

```sh
npm test
npm run lint
npx oxfmt --check
VITE_BASE_PATH=/subpath/ npm run build
```

تُنشَر نسخة GitHub Pages تلقائيًّا من الفرع `main`. يأخذ البناء مسار الموقع
من GitHub نفسه، لذلك تعمل النسخ المتفرعة وتغييرات اسم المستودع بلا تعديل في
المصدر.
